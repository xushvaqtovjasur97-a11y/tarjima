## 4. Методология

### 4.1. Кўрсаткичлар ва чегаралар (2-jadval) [16-бет; рус. 47-бет]
«Bu mezonlar asosan xalqaro standartlar (IFRS, Basel III) va Markaziy bank amaliyotiga tayangan holda tuzilgan.» [15–16-бет]

| Гуруҳ | Кўрсаткич | «Meʼyor intervali» |
|---|---|---|
| Foydalilik | ROA | ≥ 1.5% |
| | ROE | ≥ 15% |
| | NPM (sof foyda marjasi) | ≥ 25% |
| Faollik | ATR (aktivlar aylanuvchanligi) | 0.05 < ATR < 0.10 |
| | LTAR (kreditlar/aktivlar) | 50% < LTAR < 70% |
| Risk va sifat | NPL | 5% < NPL < 10% |
| | PC (zaxiralar bilan taʼminlanganlik) | 80% < PC < 100% |
| | CAR | 10% < CAR < 13% |
| Likvidlik va toʻlov qobiliyati | CR (qisqa muddatli toʻlov qobiliyati) | 1.0 < CR < 1.5 |
| | LCR | 90% < LCR < 99% |
| | LDR | 70% < LDR < 90% |
| ASI (aktivlar samaradorligi indeksi) | 0–100% | 0–60%: Samarasiz; 60–79%: Qoniqarli; 80–100%: Samarali |

- **ASI** — интеграл индекс; аммо автореферата ASI ни ҳисоблаш формуласи, нормаллаштириш усули, кўрсаткич вазнлари келтирилмаган; амалий ҳисоб-китоб (банклар бўйича ASI қиймати) ҳам берилмаган.
- Чегараларга танқидий изоҳ (матн далиллари асосида): NPL «5% < NPL < 10%» — «меъёр» сифатида юқори (Эгамова 3% ни, Шарипова/МБ амалиётини солиштиринг); LCR «90–99%» — 100% дан паст; CAR «10–13%» — интервал юқори чегарали; ATR 0.05–0.10 берилган, лекин 7-jadvalда ATR фоизда 9,3–21,6% [22-бет] — бирлик/ҳисоб номувофиқ. Муаллиф 24-бетда «Bazel talablari (10–13%)» деб ёзади [24-бет].

### 4.2. Эконометрика (панел регрессия) [24–27-бет]
- Объект: «aksiyadorlik tijorat “Turonbank” bankning 10 filialining» маълумотлари, 2009–2024 [24-бет]; кузатувлар сони 120 [25-бет] (16 йил × 10 филиал = 160 бўлиши керак эди — номувофиқлик).
- Ўзгарувчилар: боғлиқ — ln_as (активлар); мустақил — ln_cr (капиталлашув даражаси), ln_lm (ресурс «узун пуллар»), ln_nb (ҳудуддаги рақобатчи банклар сони); ln_ar (ўртача фоиз ставкаси) ва ln_nc (мижозлар сони) юқори корреляция туфайли чиқарилган [24-бет].
- 9-jadval: pooled / FE / RE; FE: ln_cr 0.6369***, ln_lm 0.3606***, ln_nb −0.8493***, R² 0.9684 [25-бет]; дастур Eviews-12.0 [25-бет, 16-изоҳ].
- Hausman: χ² = 24.861193, df = 3, p = 0.0000 → FE танланган [26-бет]; Hausman формуласи (1) келтирилган [26-бет]. (Матнда нол гипотеза талқини чалкаш: «nolinchi gipotezada oʻzgarmas effekt modeli qabul qilinadi» [26-бет].)
- Талқин: капиталлашув 1% ↑ → активлар 0.6369% ↑; узун пуллар 1% ↑ → 0.3606% ↑; рақобатчи банклар 1% ↑ → 0.8493% ↓ [27-бет]. Русча нусхада узун пуллар учун «приводит к уменьшению стоимости активов банков на 0,3606 процента» [58-бет] — таржима хатоси.
- «2030 yilga qadar aktivlarni samaradorligi prognoz koʻrsatkichlari» илмий янгилик сифатида эълон қилинган [11-бет], лекин прогноз рақамлари автореферата йўқ.

## 6. Илмий янгилик, хулоса ва таклифлар

Илмий янгилик [11-бет]:
1. ROA ≥ 1,5%, ROE ≥ 15%, NPM ≥ 25% асосида даромадлилик коэффициентларини комплекс қўллаб соф фойдани аниқлаш усули;
2. 0.05 < ATR < 0.10 ва 50% < LTAR < 70% меъёрлари асосида фаоллик баҳоси;
3. NPL 5–10%, захиралар билан таъминланганлик 80–100% асосида актив сифати ва хавф даражасини комплекс баҳолаш;
4. ASI бўйича «samarasiz» 0–60%, «qoniqarli» 60–79%, «samarali» 80–100% тоифалари;
5. FE модели асосида 2030 йилгача прогноз.
Хулоса (8 банд) [31–32-бет]: «bank aktivlari samaradorligi» тушунчаси ишлаб чиқилган; усуллар таснифи; корпоратив бошқарув; хусусийлаштириш; «Tijorat banklar aktivlari samaradorligiga ichki va tashqi omillar taʼsirini baholashning integrallashgan axborot tizimini tashkil etishdagi muammolar bank xizmatlari sifatini pasayishining asosiy sabablaridan biri» [32-бет].

## 7. Maxmudov диссертацияси учун фойдали жойлар

- LDR 70–90% [16-бет] — ликвидлик блокидаги LTD учун оралиқ чегара мисоли.
- Танқид учун: NPL «5–10%» ва LCR «90–99%» «норма» сифатида [16-бет] миллий регулятив талаблар ва Эгамова тавсия этган 3% билан зид — Maxmudov чегараларни регулятор меъёрлари ва халқаро амалиётга боғлаб асослашини таъкидлаш учун.
- Иқтибос: «Bu mezonlar asosan xalqaro standartlar (IFRS, Basel III) va Markaziy bank amaliyotiga tayangan holda tuzilgan.» [15–16-бет] — МҲХС ва Базелни чегаралар манбаи сифатида тилга олган яккаю ягона жой; аммо миллий ҳисобот ва МҲХС фарқи таҳлил қилинмаган (Maxmudov учун gap).
